# Yu_ キャプチャ

3DSの映像・音声を無線で視聴・録画するアプリです。

## ダウンロード

| 対応OS | バージョン | ダウンロード |
| --- | --- | --- |
| Android 8.0以降 | ver.y10 | [APK](https://github.com/Yu08083/Yu_Capture/releases/download/android-ver.y10-ios-ver.y06/Yu_Capture-ver.y10.apk) |
| iOS 16以降 | ver.y06 | [IPA](https://github.com/Yu08083/Yu_Capture/releases/download/android-ver.y10-ios-ver.y06/Yu_Capture-iOS-ver.y06.ipa) |

AndroidはAPKを開いてインストールします。iOSのIPAは未署名です。利用者自身のApple IDでAltStore Classicなどを使って再署名し、導入してください。

## 接続

1. 3DSに[Luma3DS 13.4Y ver.y16以降](https://github.com/Yu08083/Luma3DS-13.4Y/releases/latest)を導入します。
2. 3DSとスマートフォンを同じWi-Fiに接続します。
3. 3DS側で映像・音声送信をONにします。
4. アプリへ3DSのIPアドレスを入力し、「接続」を押します。

iOSではローカルネットワークへの接続を許可してください。撮影・録画の保存には写真への追加を許可します。

「両画面」「上画面」「下画面」を切り替えられます。「撮影」「録画」で保存し、映像をタップすると全画面に切り替わります。

設定の「軽量補間」は標準ONです。小さな動きを予測して視聴映像を補い、処理が重い場面では省略します。違和感がある場合はOFFにできます。写真・録画には元の受信映像を保存します。

実機での滑らかさ・長時間録画は未確認です。
